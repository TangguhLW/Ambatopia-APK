# Conflicts and missing data

Six simulator/native mappings disagree and are excluded from native overrides,
including Ultra World Spray and newer Immortal entries. Both source versions are
retained in provenance; no thumbnail silently replaces a verified native sheet.
Native menu easing, exact terrain generation and all equipment animation anchors
are not established by texture files alone. Area lock coverage currently uses a
creative approximation. Some specialized online machine/gacha/consumable commands
are not ported to SQL and return an explicit unsupported response.
Missing mapped core assets halt startup with a diagnostic. Failed imports retain
the active catalogue and manifest instead of publishing partial output.
