Earlier reports follow for context.

## Historical notes

[0.18 update](UPDATE-018.md). Source arm/sleeve/pupil composition and punch interval were corrected after a new device retest. The phone initially had separate 0.10 main and 0.17 QA packages. Native special hooks and retained terrain now work, and the bounded Android weather surface meets the extended local frame-budget scenarios on the test Xiaomi. This does not certify all costumes: 265 special records have flagged advanced instructions still partially supported. The older entries below are historical context where superseded by the 0.17 report.

Current direction is native Godot with imported reference wardrobe, not the full web runtime. See [0.16 update](UPDATE-016.md) for current builds, 77/77 Windows and physical Android checks, and measured performance. Regular wardrobe mapping improved; the broader custom-renderer, special effect and crowded-online backlog below is still open. The phone's effect-heavy QA frame median was 28.624 ms; stable 60 FPS is not established.

- Legendbot-009 full mech assembly, rides, complete sleeves and the remaining XML instruction set are still incomplete. Eight selected native XML visual paths now work; this is not all 317 local XML files. Battlegrid Helmet was inspected but excluded because its slot anchor needs verification. It is not advertised as an accurately reconstructed costume.
- Exact native punch easing, all speech/blink timing, additive shaders, detailed particle options and every item-specific gameplay effect remain unverified. Native frame/curve data does not prove the whole official behavior.
- Nine live concurrent accounts passed bounded motion/chat/block/lock tests. Sustained all-player 10 Hz motion, higher traffic, automatic reconnect, event retention, authoritative anti-cheat physics and all specialized Supabase machine/gacha commands remain work. No unlimited or zero-lag claim.
- The Xiaomi now passed 71 exported checks and an Android OS backpack swipe. Physical Windows/phone online co-play, IME/autofill, cutouts, other GPUs and every Android orientation remain unverified.
- Local generator and some lock-area algorithms remain approximations. Existing 128 wiki enrichments are preserved; third-party search suggestions are not authoritative item identities.
- Use the versioned 0.14 final Windows EXE. The original 0.12 player window and old local QA server remain untouched. A resource-pack update counter does not prove that old compiled code was replaced.
- A clean Windows machine without the native installation was not available. Packaged relative assets and source hashes were checked. The phone has no dependency on the PC's native installation path.

These are tracked incomplete requirements, not silently skipped or represented as finished. Hardware absence and the former two-player-only verification are no longer current limitations. Details and evidence: [0.14 update](UPDATE-014.md).
