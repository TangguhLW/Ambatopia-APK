# Menu reference

Native panel_up is a 32×32 nine-slice with nine-pixel margins. The same verified
frame is tinted for button states; no extra hover frame is claimed. Caption
displacement and transition easing are approximations, not recovered timings.
Native control crops use original dimensions rather than padded texture size.
Left/right source bounds are 135×95; jump/punch are 100×98. UI captures for
844×390, 390×844 and 320×568 are in `evidence/local-resource-update/ui`.
The persistent Windows preview remains open during local pack updates.
