Jangan menganggap port atau proses game diizinkan hanya karena SSH tersedia. Belum ada pendaftaran, pesan WhatsApp, pemesanan atau aktivasi layanan yang dilakukan.

## Kebutuhan deployment proyek ini

Game memakai WebSocket, sehingga WSS di TCP 443 bisa diproksikan menuju listener Godot privat. Broker akun Node juga harus berada di belakang HTTPS; Supabase ambatopia-godot menyimpan data permanen, bukan menjadi pengganti proses simulasi game. Secret Supabase tetap di server. Endpoint dan build Linux harus disiapkan sesuai arsitektur VPS. Jangan mengekspos mode QA atau port pengujian lokal ke Internet.

Belum ada uji latensi Internet atau deployment VPS. Rekomendasi Oracle adalah penilaian berdasarkan resource dan kebutuhan proses server, bukan bukti performa game di layanan tersebut.
