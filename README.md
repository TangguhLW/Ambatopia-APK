## Dokumentasi proyek

Proyek Godot independen untuk Android dan Windows. Buka `project.godot` menggunakan Godot 4.7.2.

Catatan versi terbaru: [0.34.1](docs/resources/UPDATE-034.md). Dokumentasi historis: [README.history.md](README.history.md).

APK memakai debug signing seperti paket lokal yang telah diuji. Tiga pemeriksaan Android mengenai seed/provider/growth masih gagal karena RPC Supabase belum diperbarui. Migrasi disiapkan di `supabase/growth-deploy.sql`, tetapi belum diterapkan. Detail keterbatasan dan hasil pengujian tercantum pada catatan versi.
